# おうちトーク — 家族専用チャット

登録なし・完全無料で使える、LINEのような家族チャットです。
スマホのブラウザで開くWebアプリなので、アプリストアからのインストールも不要です。

## できること

- テキスト・スタンプ・写真のやりとり
- 日付ごとの表示、URLのリンク化、送信済み／未送信の表示と再送
- 招待リンクで家族を簡単に追加
- ホーム画面に追加すると普通のアプリのように起動
- **アプリを閉じていても届く通知**（Web Push。設定すると使えます）

## ファイル構成

| ファイル | 置き場所 | 役割 |
| --- | --- | --- |
| `index.html` | GitHub Pages | アプリ本体（画面・暗号化・送受信） |
| `sw.js` | GitHub Pages | 裏で動く小さなプログラム。通知を受け取って表示する |
| `manifest.webmanifest`, `icon*` | GitHub Pages | ホーム画面に追加するための情報とアイコン |
| `worker/worker.js` | Cloudflare Workers | 通知の中継役（通知を使う場合だけ） |

## 設計

### 全体像

```
                    ┌──────── メッセージ本体 ────────┐
 スマホA ──暗号文──▶  公開中継サーバー（Nostrリレー×5）  ──暗号文──▶ スマホB（開いているとき）
    │
    │ ②「新着あり」を依頼（中身は暗号化済み）
    ▼
 通知中継（Cloudflare Worker） ──③ Web Push ──▶ Google / Apple / Mozilla の配信網 ──④──▶ スマホB（閉じていても）
    ▲                                                                                 │
    └──────────────── ①「この端末に通知を届けて」と登録（最初に1回） ─────────────────┘
```

メッセージ本体と通知は**別の道**を通ります。

- **メッセージ本体**：これまでどおり、公開中継サーバー（Nostrリレー）経由。アプリを開くと届きます。
- **通知**：Cloudflare Workerが受け取り、スマホの配信網（AndroidはGoogle、iPhoneはApple）に渡します。配信網がスマホを起こして通知を出すので、アプリを閉じていても届きます。

### なぜ中継役（Worker）が必要か

Web Pushでは、通知を送る側が「送信元の証明書（VAPID鍵）」で署名し、配信網に直接届ける必要があります。ブラウザの中からはこれを直接送れない（配信網がブラウザからの送信を受け付けない）ため、小さな中継役を1つ置きます。Cloudflare Workersの無料プランは1日10万リクエストまで無料です。家族チャットなら上限に届くことはまずありません。

### データの流れ

1. **登録（端末ごとに最初の1回）**
   - 設定で「通知をオンにする」を押す → スマホが通知を許可。
   - ブラウザが、その端末専用の「通知の宛先」を発行します（配信網のURLと、その端末だけが持つ暗号鍵）。
   - アプリは宛先をWorkerに送ります。Workerは「家族の目印」ごとにまとめてKV（Cloudflareの無料の保存場所）に保管します。
2. **送信**
   - Aさんがメッセージを送ると、アプリはNostrリレーに本体を送ります。続けて、Workerに「家族に知らせて」と依頼します。
   - 依頼には、名前と先頭100文字のプレビューを**家族の合言葉で暗号化**したものだけを入れます。
3. **配信**
   - Workerは、同じ家族の目印で登録された端末のうち、**送信者以外**に通知を送ります。
   - 送るときは、端末ごとの鍵でさらに暗号化（RFC 8291）し、VAPID鍵で署名（RFC 8292）します。
4. **表示**
   - スマホの `sw.js` が通知を受け取ります。端末内に保存してある家族の鍵でプレビューを開き、「おかあさん：今日は何時に帰る？」のように表示します。
   - 通知をタップすると、おうちトークが開きます。

### 安全性の考え方

| 誰が | 見えるもの | 見えないもの |
| --- | --- | --- |
| Nostrリレー | 暗号文、会話の目印 | 本文、名前、合言葉 |
| Cloudflare Worker | 家族の目印（会話の目印とは別の値）、端末の通知宛先、送信の時刻 | 本文、名前、合言葉 |
| Google / Apple の配信網 | 通知が届いた時刻 | 中身（端末の鍵で暗号化済み） |

- 家族の目印は、合言葉から作る一方向の値（PBKDF2）です。目印から合言葉を逆算することはできません。
- VAPID鍵は、Workerが最初に呼ばれたときに自動で作ってKVに保存します。手作業での鍵の生成や貼り付けは不要です。
- Workerは、`ALLOWED_ORIGIN` に設定したサイト（あなたのGitHub Pages）からの呼び出しにだけ応じます。
- 通知をやめた端末（配信網が「もう存在しない」と返した宛先）は自動で削除します。

### 無料枠の目安

| 項目 | 無料枠 | 家族5人・1日200通の場合 |
| --- | --- | --- |
| Workers のリクエスト | 10万回/日 | 約200回 |
| KV の読み出し | 10万回/日 | 約200回 |
| KV の書き込み | 1,000回/日 | ほぼ0（登録・解除のときだけ） |

## 公開のしかた（最初に1回だけ）

### 1. アプリ本体を GitHub Pages に置く

家族がスマホで開ける場所に、アプリを置きます。公開作業をする人だけGitHubへの登録が必要です。**家族はアカウント不要**です。

1. https://github.com で無料登録し、右上の「＋」→「New repository」。名前は例えば `ouchi-talk`、**Public** を選んで作成。
2. 作成直後の画面で「uploading an existing file」を押します。`worker` フォルダ以外の全ファイル（index.html, sw.js, manifest.webmanifest, icon.svg, icon-180.png, icon-192.png, icon-512.png）をドラッグして「Commit changes」。
3. 「Settings」→ 左メニュー「Pages」→ Branch を `main` / `(root)` にして「Save」。
4. 1〜2分後、`https://あなたのユーザー名.github.io/ouchi-talk/` で開けるようになります。

ここまでで、チャットとしてはもう使えます。以下は、閉じていても届く通知を使う場合の手順です。

### 2. 通知の中継役を Cloudflare Workers に置く

1. https://dash.cloudflare.com/sign-up で無料登録（クレジットカード不要）。
2. **保存場所を作る**：左メニュー「ストレージとデータベース（Storage & Databases）」→「Workers KV」→「Create instance」。名前は `ouchi-push-subs`。
3. **Workerを作る**：左メニュー「Workers & Pages」→「Create」→「Start with Hello World!」。名前を `ouchi-push` にして「Deploy」。
4. **コードを入れる**：できたWorkerの画面で「Edit code」。最初から入っているコードを全部消し、`worker/worker.js` の中身を貼り付けて「Deploy」。
5. **保存場所をつなぐ**：Workerの「Settings」→「Bindings」→「Add」→「KV namespace」。
   - Variable name：`SUBS`（半角大文字・このとおりに）
   - KV namespace：手順2で作った `ouchi-push-subs`
6. **呼び出し元を設定**：「Settings」→「Variables and Secrets」→「Add」。
   - Type：Text、Variable name：`ALLOWED_ORIGIN`、Value：`https://あなたのユーザー名.github.io`
   - 末尾の `/` や `/ouchi-talk` は付けません。
7. Workerの画面上部に出ている URL（例：`https://ouchi-push.あなたの名前.workers.dev`）を控えます。
8. **動作確認**：ブラウザで `https://ouchi-push.〜.workers.dev/vapid` を開きます。`{"error":"origin_not_allowed"}` と出れば、Workerは動いています（アプリ以外から直接開いたときは、わざと断るようにしてあります）。

> 管理画面の表記は変わることがあります。見つからないときは、似た名前のメニューを探してください。

### 3. アプリに中継役の URL を書き込む

1. GitHubのリポジトリで `index.html` を開き、右上の鉛筆マーク（Edit）を押します。
2. 次の1行を探して、手順2-7で控えたURLを入れます。

   ```js
   const PUSH_URL = "";
   ```
   ↓
   ```js
   const PUSH_URL = "https://ouchi-push.あなたの名前.workers.dev";
   ```
3. 「Commit changes」。1〜2分で反映されます。

## 家族のスマホに入れる

### Android

1. 招待リンクをChromeで開き、呼び名を入れて「はじめる」。
2. 右上の︙ →「ホーム画面に追加」（または「アプリをインストール」）。
3. おうちトークの設定 →「通知をオンにする」→ 許可。

### iPhone（iOS 16.4以降）

iPhoneでは、**ホーム画面に追加したアイコンから開いたときだけ**、閉じているときの通知が使えます。

1. 招待リンクを **Safari** で開く。
2. 共有ボタン（□に↑）→「ホーム画面に追加」。
3. **ホーム画面のアイコンから**おうちトークを開き、呼び名と合言葉を入れて「はじめる」。
   - iPhoneでは、Safariとホーム画面のアプリで保存場所が別になります。ホーム画面から開いたときに、合言葉をもう一度入れる必要があります。招待リンクを送るときは、合言葉も口頭などで伝えておいてください。
4. 設定 →「通知をオンにする」→ 許可。

### 招待リンク

最初の人が設定 →「招待リンクをコピー」で作れます。合言葉が入ったリンクなので、家族以外には送らないでください。

## 知っておいてほしいこと

- **通知は「新着のお知らせ」で、本文は開いてから届きます。** 通知にはプレビュー（先頭100文字）が出ます。全文と写真は、アプリを開いたときにNostrリレーから受け取ります。
- **通知が届かないとき**：省電力モードやおやすみモード、端末の通知設定を確認してください。Androidでは、Chromeの通知が許可されている必要があります。
- **履歴はおよそ30日分**を中継サーバーから取り寄せます。端末内には最新800件を保存します。
- **写真は自動で小さく**して送ります（1枚約50KB）。動画やファイルは送れません。
- 合言葉を変えると別のトークになります。家族全員で同じ合言葉を使ってください。

## 調整したいとき

`index.html` の上の方にある設定で変えられます。

| 項目 | 内容 |
| --- | --- |
| `PUSH_URL` | 通知の中継役（Cloudflare Worker）のURL。空なら、開いている間だけの通知 |
| `RELAYS` | 使う中継サーバーの一覧 |
| `HISTORY_DAYS` | 初回に取り寄せる過去の日数 |
| `STAMPS` | スタンプとして並べる絵文字 |
| `COLORS` | アイコンの色の候補 |
